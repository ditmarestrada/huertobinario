Acceso a datos en Java

De JDBC a Spring Data JPA: qué capa hay encima de cuál, qué opciones existen para hablar con una base de datos, qué cambia entre ellas y cuándo usar cada una. Pulsa una pieza, filtra la tabla o recorre los conceptos.

En 30 segundos
  • JPA es el contrato, Hibernate lo implementa y Spring Data JPA te ahorra escribir los repositorios.
  • Si necesitas controlar el SQL (reportes, consultas pesadas), usa JdbcTemplate.
  • El problema que más duele en producción es el N+1: 1 lista, 1 consulta extra por cada fila.
